The sweep, Monte Carlo, AC sweep and SPICE `.tran` results now say which engine produced them. Every result has `engine` (`"classic"` or `"core"`) and `fallbackReasons`, the reasons a run is on classic when it was not asked to be (for example `unsupported-kind:signal_gen`). Every sweep, Monte Carlo and AC spec takes an optional `engine`: `"auto"` (the default), `"classic"` or `"core"`, and the runner hooks take the same option, which wins over the spec's. One engine is chosen for a whole run, after every point has been compiled. `auto` uses the Rust/WASM core only when every point of the run is supported: a sweep or Monte Carlo of a circuit made only of kinds in `CORE_SUPPORTED_KINDS` runs on the core and says so (`engine: "core"`), and any other circuit runs on classic with the reason, so those results come from the core's solver, not classic's. `"core"` throws instead of falling back. The runner hooks also take an optional `onRestart(reasons)`: if the core declines a later point or fails mid-run (a solve that does not converge, a trap, a poisoned instance), the whole run is replayed on classic and `onRestart` is called once first, so a progress display can start over. The AC sweep and `.tran` stay on classic for now and record why.
